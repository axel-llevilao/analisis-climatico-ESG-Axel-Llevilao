climachile

Plataforma abierta de datos para el análisis de riesgo climático físico y de transición en Chile, desarrollada por Axel Llevilao.

climachile-rclone

climachile-rclone es la aplicación OAuth de uso personal que el proyecto usa para sincronizar archivos de datos entre los equipos del autor y su propio Google Drive, mediante la herramienta de código abierto rclone. Solo accede a los archivos que ella misma crea (permiso drive.file), dentro de la carpeta climachile-data. No es un servicio para terceros.
